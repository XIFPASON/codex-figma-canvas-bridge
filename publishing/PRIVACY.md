# Design Handoff Exporter 隐私说明草稿

本说明对应 `output/community` 的离线候选版本，不适用于另行分发的本地同步开发版本。

插件仅在用户主动点击导出时读取选中节点及其子树、图片，以及可访问的关联组件、样式和变量数据。读取的数据包括设计文字、布局、视觉属性、图像、组件标识和文件/页面名称。

市场候选版不发送网络请求，不将设计上传至发布者服务器，不使用遥测、广告或分析服务，不要求第三方账户或 API Key。导出内容在插件运行期间保留于内存，用户保存后成为本地文件；关闭插件结束其运行。插件不修改设计图层。

本地导出文件可能包含敏感设计文字和图片。用户自行决定保存、分享或删除文件。将文件交给外部开发工具或 AI 工具时，数据的后续处理取决于用户选择的工具及其服务条款，不由本插件自动触发。

字体二进制不会导出。素材使用权、字体安装和设计文件访问权限由用户自行确认。

发布前需由发布者确认此说明、补齐支持联系方式、公开托管地址及生效日期，并在实际发布行为与数据处理变化时维护内容。
